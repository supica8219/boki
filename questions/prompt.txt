  簿記クイズ 問題作成ガイドライン
════════════════════════════════════

【このセットの目的】
✓ 解説教材ではなく、「1問ずつ理解しながら解けるUI用クイズ」
✓ 現在の画面だけで解ける完全独立した問題
✓ 1問 = 1つの理解 + 1つの計算

────────────────────────────────────
【問題タイプと基本ルール】
────────────────────────────────────

■ type: "choice" （選択問題）

  形式：
  - question: 問題文
  - desc: 補足情報（この画面だけで解けるために必要な全情報を記載）
  - choices: [選択肢1, 選択肢2, 選択肢3, 選択肢4]
  - answer: 正解の配列番号（0, 1, 2, 3）※値ではなく番号

  例：
  choice: [1900, 1960, 2000, 2100]
  answer: 1  ← "1960" ではなく、配列の1番目という意味


■ type: "input" （仕訳問題）

  形式：
  - question: 問題文
  - desc: 仕訳情報（全必要情報を記載）
  - accounts: [科目名, 科目名, ...]
  - choices: [0, 金額1, 金額2, ...]（0は区切り、以降が使用金額）
  - answer: [
      { key: "科目キー", side: "借方" or "貸方", amount: 金額 },
      ...
    ]

  ルール：
  ✓ 同じ科目が複数行登場しない（複数登場する場合は合算する）
  ✓ 「どの科目にどの金額を入れるか」が明確な問題のみ
  ✓ 計算が必要な場合は事前に計算問題として出題


────────────────────────────────────
【問題設計の3つの原則】
────────────────────────────────────

【原則1】1問は1画面で完結
  
  NG：前問の情報を前提にした問題
  OK：descに必要情報をすべて再掲する
  
  例：
  NG「差額を計算してください」（前問で計算した値を前提）
  OK「実際有高 350,500円、帳簿残高 332,000円、差額はいくら？」


【原則2】複雑な計算は細かく分解

  NG：「完成品原価はいくら？」（1問で完成品単価→数量計算→合計をやる）
  
  OK：段階的に出題
  1. 「原価合計を求めてください」
  2. 「完成品単価を求めてください」
  3. 「完成品原価を求めてください」


【原則3】descの書き方

  ✓ 視認性：改行やタグを活用（<br>で改行）
  ✓ 完結性：その問題を解くために必要な情報をすべて記載
  ✓ 明確性：余計な説明は不要、必要な数字だけ


────────────────────────────────────
【commentの書き方】
────────────────────────────────────

【構成】（必ずこの順序）

  1. 解き方の原理（1～2行）
  2. 計算式（複数ある場合は段階的に）
  3. 最終答え

  例：
  comment: "実際有高から帳簿残高を差し引く。<br>
            350,500 - 332,000 = 18,500円<br>
            答え：18,500円"


【禁止事項】

  ✗ 理論説明
    NG：「正常減損は完成品負担である」
    OK：「正常減損は完成品に負担させるため」

  ✗ 背景説明
    NG：「複式簿記では...」
    OK：「差引額を求める」

  ✗ 重複情報
    NG：commentで再度descを繰り返す
    OK：計算手順と答えのみ


【記号】

  ✓ 改行は <br> を使用
  ✓ 演算子：÷（除算）、×（乗算）、－（減算）、＋（加算）
  ✓ 単位：円、kg、個、時間など


────────────────────────────────────
【記述フォーマット】
────────────────────────────────────

{
  type: "choice",
  question: "差額はいくら？",
  desc: "実際有高 350,500円<br>帳簿残高 332,000円",
  choices: [18500, 17500, 19500, 16500],
  answer: 0,
  comment: "実際有高から帳簿残高を差し引く。<br>350,500 - 332,000 = 18,500円<br>答え：18,500円"
}


────────────────────────────────────
【文言の書き方】
────────────────────────────────────

✓ 体言止め（「です」「ます」は不要）
✓ 簡潔に（余計な修飾語は不要）
✓ 統一性（全問で表現を統一）

例：
OK：「～の計算」「～の金額」「～の差異」
NG：「～を計算してください」「～はいくらですか」

以下は禁止。

- 「理論上」
- 「〜という考え方」
- 「簿記では」
- 「原価計算では」
- 「通常は」
- 長い背景説明
- 教科書的説明
- 概念解説

────────────────────
【input問題の重要ルール】
────────────────────

input問題は、
「仕訳UIに入力する問題」

UI構造：

- 勘定科目一覧(accounts)
- 借方列
- 貸方列
- 金額候補(choices)

ユーザーは、
各科目へ借方・貸方の金額を入力する。

そのため、

input問題では必ず：

1. 科目が不足しない
2. choices金額が不足しない
3. answerがUI構造に一致する
4. 借方・貸方が明確
5. descで何を入力するか明示する

────────────────────
【input問題の良い例】
────────────────────

{
  type: "input",
  question: "差異振替仕訳を入力しよう",
  desc: "製造間接費配賦差異9,000円（借方差異）を予算差異と操業度差異へ分解する",
  comment: "借方差異9,000円を分解する。<br>操業度差異10,000円を借方へ入力する。<br>製造間接費配賦差異9,000円と予算差異1,000円を貸方へ入力する。",
  accounts: [
    "操業度差異",
    "製造間接費配賦差異",
    "予算差異"
  ],
  choices: [0, 1000, 9000, 10000],
  answer: [
    { key: "操業度差異", side: "借方", amount: 10000 },
    { key: "製造間接費配賦差異", side: "貸方", amount: 9000 },
    { key: "予算差異", side: "貸方", amount: 1000 }
  ],
  hint: ["差異振替", "操業度差異", "予算差異"]
}

────────────────────
【input問題で必須】
────────────────────

choicesには必ず0を含める。

理由：
未入力セル用。

例：

choices: [0, 1000, 9000, 10000]

────────────────────
【descのルール】
────────────────────

- 数字を整理
- 行分けする
- 必要情報だけ
- 長文禁止

────────────────────
【出力形式】
────────────────────

必ず以下のみ出力。

window.questionsData = [
  {
    ...
  }
]

余計な説明は禁止。

【問題オブジェクト仕様】
────────────────────

type:
"choice" or "input"

question:
問題タイトル

desc:
問題本文（HTML可）

choices:
選択肢

answer:
正解

accounts:
input形式の科目一覧

comment:
解き方のみ

hint:
補助ワード

────────────────────
【UI目的】
────────────────────

目的は、

「教科書説明」ではなく、

"その問題を今解けるようにする"

こと。

commentは常に、

「次も同じ問題を解けるようになる説明」

を書く。
